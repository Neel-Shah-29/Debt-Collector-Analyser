# Prodigal-Assessment
The repository provides a solution to task of Debt Collection Analyser.

### For executing the code follow the below steps
Step 1 : Clone the repository and move to Task1&2 directory.
```
git clone  <Repository URL>
```

Step 2 : Install the dependencies
```
pip install -r requirements.txt
```

Step 3: Run the streamlit Application
```
streamlit run app.py
```

Step 4: Visulizations are implemented in Jupyter Notebook under Task 3 folder.
